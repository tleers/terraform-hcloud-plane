# Support

Use GitHub Discussions for setup questions and architecture proposals. Use GitHub Issues for reproducible module defects and feature requests. Plane application behavior belongs in the upstream [Plane repository](https://github.com/makeplane/plane); Hetzner platform incidents belong with [Hetzner support](https://www.hetzner.com/support-center/).

Before requesting help, collect sanitized output from `tofu version`, `tofu providers`, `tofu validate`, `cloud-init status --long`, and `docker compose ps`. Remove tokens, secrets, email addresses, IPs when necessary, and never attach state or `plane.env`.
